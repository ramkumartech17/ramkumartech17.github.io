# Ram — Data Engineer Portfolio

A responsive, dark-theme personal portfolio built with plain HTML, CSS and JavaScript. It is designed for GitHub Pages and requires no build tools.

## Files

- `index.html` — website content and page structure
- `styles.css` — responsive dark-theme styling
- `script.js` — mobile navigation interaction
- `assets/favicon.svg` — browser tab icon

## Before publishing

1. In `index.html`, replace `ramkumartech17@gmail.com` with the email address you want recruiters to use.
2. Replace `ram-kumar-datainsights` with your LinkedIn profile slug.
3. Replace `ramkumartech17` with your GitHub username.
4. Review every experience and project statement for accuracy.
5. Add a resume PDF only if you want one publicly available. Create a `resume.pdf` file in the repository root and add a link to it in the hero or contact section.
6. Add sanitized project diagrams or links to public repositories where available. Do not publish client data, credentials, proprietary code or confidential architecture.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named exactly `ramkumartech17.github.io` (replace the placeholder with your actual GitHub username).
2. Upload the contents of this folder to the repository root. Make sure `index.html` is at the root, not inside another nested folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for the deployment to finish. Your site will be available at `https://ramkumartech17.github.io`.

GitHub Pages may take several minutes to publish the first deployment.

## Local preview

Open `index.html` in a modern browser. No package installation is required.

## Important

A GitHub Pages website is public. Do not upload personal documents or confidential information unless you intentionally want them publicly accessible.
